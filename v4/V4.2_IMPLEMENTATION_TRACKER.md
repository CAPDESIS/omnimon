# OmniMon v4.2.0 — Implementation Tracker

## 1. Frontend: UI/UX & Accessibility (Svelte)

- [x] **Resizable Tab Panel**: Tab panel height persists via preference store. Drag divider works.
- [x] **Sticky Headers**: Tab list headers use `position: sticky` so they stay visible on scroll.
- [ ] **URL Truncation**: Full URL visible on hover via `title` attr. Long-term: resizable columns or full URL in modal. → GitHub Issue
- [x] **Dynamic Font Size**: All `font-size` values use `calc(var(--base-font-size) * ratio)` — A+/A- buttons resize the entire UI proportionally.
- [x] **Text Overlap Audit**: Overflow hidden + text-overflow ellipsis on all relevant columns. No z-index stacking issues found.
- [x] **Theme Toggle**: Light/Dark/Auto with `data-theme` attribute on `<html>`. Respects system preference for auto mode.
- [x] **Search Clear Button**: Interactive `×` button clears search input instantly.

## 2. Core: Browser Introspection & Grouping (Rust)

- [x] **Safari/Chrome Parity**: Safari tabs now enumerate correctly (counter-based IDs instead of broken `id of t as text`). Safari close/focus use URL matching.
- [x] **Per-Browser RAM**: Each browser section shows its OWN RAM total (Chrome processes → Chrome RAM, Safari/WebKit processes → Safari RAM).
- [x] **Per-Browser Expand/Collapse**: Each browser section has independent expand/collapse state.
- [x] **Browser Process Grouping**: `detectBrowser()` maps Chrome Helper, WebKit.WebContent, Brave Helper, etc. to their parent browser name. Group view aggregates all children under one expandable row.
- [x] **Interactive Tab Navigation**: Clicking a tab title calls `focus_browser_tab` IPC → brings that specific tab to front in the correct browser via AppleScript.
- [x] **Multi-Select Tab Close**: Checkboxes + "Close N" button with confirmation dialog.
- [x] **Confirmation Dialogs**: All destructive actions (kill process, close tab, close all tabs) show `window.confirm()` before executing.
- [x] **Network Traffic Monitoring**: Real-time TX/RX bytes/sec displayed in StatusBar. Computed from per-interface cumulative counters via `sysinfo::Networks`.

## 3. AI: Validation & Context

- [x] **API Key Validation**: `validate_api_key` makes a lightweight test request before saving. Empty keys rejected. Auth failures show clear error.
- [x] **Key Trimming**: `trim()` applied before save and validate. Leading/trailing whitespace stripped.
- [x] **Better Error Messages**: Keyring/storage errors show "No API key configured. Go to Settings to add your API key."
- [x] **Configurable IDLE Threshold**: User-configurable CPU% threshold in Settings (0.1–10.0). Persisted across restarts.
- [ ] **Network Context for AI**: Pass network stats + open tab URLs as context to AI analysis. → GitHub Issue
- [ ] **Dynamic AI Chat**: Interactive chat mode ("What's consuming network?", "Close tabs unrelated to X"). → GitHub Issue

## 4. DevOps, Security & Community

- [x] **Cross-Platform Compilation**: macOS (AppleScript), Windows/Linux (CDP). `NativeTabProvider` dispatches correctly per platform.
- [x] **Security**: API keys stored in OS keyring (macOS Keychain, Windows Credential Store, Linux Secret Service). No keys in source. Tab ID/URL sanitization with allowlisted URL schemes.
- [x] **License**: MIT + Commons Clause (non-commercial protection).
- [x] **Git History Clean**: All `Co-Authored-By: Claude` lines permanently removed from commit history via `git-filter-repo`.
- [x] **Bilingual Docs**: README.md, ROADMAP.md in English + Spanish.
- [ ] **GitHub Sponsors**: Configure FUNDING.yml for GitHub Sponsors. → GitHub Issue
- [x] **Full i18n**: Runtime language switching (EN/ES + Auto) with persisted preference. ~130 keys across 6 components.
- [ ] **SECURITY.md Update**: Add CVE scanning info and responsible disclosure process. → GitHub Issue

- **Rust**: 4 integration tests — all passing
