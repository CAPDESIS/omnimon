# OmniMon v4.3.0 — Implementation Tracker

## 1. CSS Accessibility & Font Scaling

- [x] **Font Size Binding Fix**: All fixed pixel heights (`height: 28px`, `20px`, etc.) converted to `calc(var(--base-font-size) * ratio)` across toolbar, status bar, process table rows, tab rows, and settings modal inputs.
- [x] **MAX_FONT_SIZE Raised**: From 24 → 48, allowing comfortable use on large/4K monitors.
- [x] **Virtual Scroll Dynamic Row Height**: `ROW_HEIGHT` in ProcessTable now derives from `$fontSize * 1.667` instead of a hardcoded `20px`, ensuring virtual scroll math matches CSS.
- [x] **Z-Index / Overflow Fix**: `min-width: 0` added to tab panel and chrome-manager to prevent text overflow from expanding parent containers. `overflow-x: hidden` on chrome-manager prevents horizontal scroll bleed.
- [x] **Sticky Headers**: ProcessTable `thead` remains `position: sticky; top: 0; z-index: 2`. ChromeTabManager tab list header retains `position: sticky; top: 0; z-index: 1`.

## 2. Safari & Browser Grouping

- [x] **Safari AppleScript Robustness**: Safari `list_safari_tabs()` now wraps `tabs of w` access in try/on-error blocks to skip non-tab windows (Downloads, History, Preferences). Individual tab title/URL reads also wrapped in try blocks to prevent one bad tab from failing the entire enumeration.
- [x] **Broader Browser Detection (Rust)**: `get_metrics()` group tagging expanded to catch main browser app processes (e.g., `Google Chrome`, `Brave Browser`, `Microsoft Edge`, `Arc`, `firefox`) in addition to helper processes.
- [x] **Broader Browser Detection (Frontend)**: `detectBrowser()` in ProcessTable, ChromeTabManager, and ProcessDetailsModal updated to match main app executables (not just helpers) and added Firefox support.

## 3. Dynamic AI & OpenRouter

- [x] **AI Chat Input**: New always-visible text input below process table for free-form AI questions. Includes clear "X" button, Enter-to-submit, loading state, and error display. System context (top 10 processes by RAM) automatically appended to user questions.
- [x] **OpenRouter Headers**: All OpenRouter API calls now include required `HTTP-Referer` and `X-Title` headers for proper API compliance.
- [x] **OpenRouter Validation**: `validate_api_key()` now uses a valid OpenRouter model (`meta-llama/llama-3.2-3b-instruct:free`) instead of `gpt-4o-mini` when validating OpenRouter keys.

## 4. i18n

- [x] **New Keys**: Added `ai.chatLabel`, `ai.chatPlaceholder`, `ai.ask` to both EN and ES locale files for the new AI chat input.

## Test Coverage

- **Frontend**: Vitest tests — all passing
- **Rust**: Integration tests — all passing
- **Build**: Zero warnings (Vite + Cargo)

# OmniMon v4.3.0 — Rastreador de Implementación

## 1. Accesibilidad CSS y Escalado de Fuente

- [x] **Corrección del Binding de Font Size**: Todas las alturas fijas en píxeles convertidas a `calc(var(--base-font-size) * ratio)` en toolbar, barra de estado, filas de tabla, filas de pestañas e inputs del modal de ajustes.
- [x] **MAX_FONT_SIZE Aumentado**: De 24 → 48, permitiendo uso cómodo en monitores grandes/4K.
- [x] **Altura de Fila Dinámica en Virtual Scroll**: `ROW_HEIGHT` ahora deriva de `$fontSize * 1.667` en vez de `20px` hardcoded.
- [x] **Corrección Z-Index / Overflow**: `min-width: 0` y `overflow-x: hidden` agregados para prevenir desbordamiento de texto.
- [x] **Headers Sticky**: ProcessTable `thead` mantiene `position: sticky`. ChromeTabManager tab list header mantiene sticky.

## 2. Safari y Agrupación de Navegadores

- [x] **Robustez del AppleScript de Safari**: `list_safari_tabs()` ahora maneja ventanas sin pestañas (Descargas, Historial, Preferencias) con bloques try/on-error.
- [x] **Detección Ampliada de Navegadores (Rust)**: Etiquetado de grupo expandido para incluir procesos principales del navegador además de helpers.
- [x] **Detección Ampliada de Navegadores (Frontend)**: `detectBrowser()` actualizado en los 3 componentes para detectar ejecutables principales y Firefox.

## 3. IA Dinámica y OpenRouter

- [x] **Input de Chat IA**: Nuevo campo de texto siempre visible para preguntas libres a la IA. Incluye botón "X" para limpiar, Enter para enviar, estado de carga y display de errores.
- [x] **Headers OpenRouter**: Todas las llamadas API a OpenRouter ahora incluyen `HTTP-Referer` y `X-Title` requeridos.
- [x] **Validación OpenRouter**: `validate_api_key()` ahora usa un modelo válido de OpenRouter para validar claves.

## 4. i18n

- [x] **Nuevas Claves**: Agregadas `ai.chatLabel`, `ai.chatPlaceholder`, `ai.ask` en archivos de locale EN y ES.

## 5. CLI ↔ GUI Parity (v4.4.0)

- [x] **CLI Shared Settings**: CLI reads and writes to `~/Library/Application Support/com.omnimon.desktop/preferences.json`, mirroring the GUI automatically.
- [x] **CLI Tab Management**: Added `tabs list`, `tabs close`, and `tabs focus` via CLI using the unified core tab abstractions.
- [x] **CLI AI Chat & API Keys**: Complete terminal parity for the GUI's AI Chat and system optimization features (`chat`, `apikey` commands).
- [x] **Cross-Platform Readiness**: Ensured networking and configurations correctly operate across all supported compilation targets.
