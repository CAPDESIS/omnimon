## English
This document tracks the progress and tasks for the OmniMon v4.3.0 sprint.

### 1. 💻 UI/UX & Accessibility (Svelte)
- [ ] **Fix Text Overlaps:** Audit and fix Z-Index issues where texts overlap on low-resolution screens or during window resizing. (See Issue #17)
- [ ] **Logo Redesign:** Implement the new visual identity and application logo. (See Issue #18)

### 2. 🧠 AI Expansion & Local Providers
- [ ] **Local AI Support:** Implement connections to local providers (Ollama, Llama.cpp) for 100% offline and private AI operations. (See Issue #19)

### 3. 🌐 Core & Cross-Platform Parity Verification
- **Audit Notes:**
  - `ai.rs`: Network calls are cleanly abstracted using `reqwest`. No OS-specific implementations detected. Fully cross-platform compatible.
  - `browser.rs`: AppleScript `osascript` is correctly guarded behind `#[cfg(target_os = "macos")]`. 
  - **⚠️ Cross-Platform Warning (Linux/Windows):** On Windows and Linux (`#[cfg(any(target_os = "windows", target_os = "linux"))]`), tab introspection relies *exclusively* on the CDP (Chrome DevTools Protocol) fallback. This means reading Safari or Firefox tabs will fail or return empty on non-macOS platforms since they do not expose CDP natively. We must ensure the UI handles these empty states gracefully without crashing on Windows/Linux.

## Español
Este documento rastrea el progreso y las tareas para el sprint de OmniMon v4.3.0.

### 1. 💻 UI/UX y Accesibilidad (Svelte)
- [ ] **Corregir Superposición de Textos:** Auditar y solucionar problemas de Z-Index donde los textos se superponen en pantallas de baja resolución o al redimensionar la ventana. (Ver Issue #17)
- [ ] **Rediseño del Logo:** Implementar la nueva identidad visual y el logo de la aplicación. (Ver Issue #18)

### 2. 🧠 Expansión de IA y Proveedores Locales
- [ ] **Soporte de IA Local:** Implementar conexiones a proveedores locales (Ollama, Llama.cpp) para operaciones de IA 100% fuera de línea y privadas. (Ver Issue #19)

### 3. 🌐 Core y Verificación de Paridad Multiplataforma
- **Notas de Auditoría:**
  - `ai.rs`: Las llamadas de red están limpiamente abstraídas usando `reqwest`. No se detectaron implementaciones específicas del sistema operativo. Totalmente compatible en múltiples plataformas.
  - `browser.rs`: El uso de AppleScript `osascript` está correctamente protegido tras `#[cfg(target_os = "macos")]`.
  - **⚠️ Advertencia Multiplataforma (Linux/Windows):** En Windows y Linux (`#[cfg(any(target_os = "windows", target_os = "linux"))]`), la introspección de pestañas depende *exclusivamente* del CDP (Chrome DevTools Protocol) como respaldo. Esto significa que leer pestañas de Safari o Firefox fallará o retornará un estado vacío en plataformas que no sean macOS, ya que no exponen CDP de forma nativa. Debemos asegurarnos de que la UI maneje estos estados vacíos de manera elegante sin colapsar en Windows/Linux.
