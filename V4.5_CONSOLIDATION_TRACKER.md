# OmniMon v4.5.0 - Ecosystem Consolidation & Documentation Tracker

## 1. 1:1 Mirror Unification (CLI ↔ GUI ↔ Core)
- [x] **Core API Unification**: Validated that `v4/crates/core` is the singular source of truth for both the CLI and GUI tools.
- [x] **Synced Process Filtering**: Ensured the CLI passes processes through `is_immutable_blocked_process_name` before and after AI analysis (matching GUI limits, sending `memory_mb`, and filtering to a standard limit of 30).
- [x] **Unified Settings Structure**: Ensured that the settings configuration `preferences.json` applies identically across the GUI and CLI, preventing divergent states.
- [x] **Consistent AI Output**: Validated that the `optimize` and `chat` commands fetch and output data that matches the frontend representations.

## 2. Edge-Case & Background Performance
- [x] **System Tray Suspend**: Verified that GUI metrics polling and animations suspend appropriately on window blur/hide, saving CPU ticks.
- [x] **Accurate Memory Readings**: Resolved issue where `swap_used_mb` was incorrectly hardcoded in the frontend by ensuring it pulls from the `sys_state` watcher cache.
- [x] **Network Fallbacks**: Ensured `ai.rs` network errors bubble gracefully to the CLI/GUI without hanging, applying connection timeouts in `reqwest`.

## 3. Exhaustive Enterprise Documentation
- [x] **CLI Manual**: Created `docs/CLI_MANUAL.md` with complete usage, descriptions, arguments, and examples for every command (`status`, `kill`, `optimize`, `tabs`, `chat`, `apikey`, `settings`).
- [x] **Codebase Docs (TSDoc / Rustdoc)**:
  - **Rust**: Added `///` rustdoc to all public items inside `killer.rs`, `metrics.rs`, `watcher.rs`, `ai.rs`, and `browser.rs`.
  - **TypeScript**: Added `/** */` TSDoc blocks to the main app stores and IPC interfaces (`ipc.ts`, `processes.ts`, `preferences.ts`).

## 4. Security & Dependency Check
- [x] **API Error Sanitization**: Mitigated HIGH severity risk where API Keys (`Authorization` headers) could potentially leak through raw HTTP error bodies from upstream providers. Error messages are now scrubbed and return standardized status codes.
- [x] **CSP Strengthening**: Added `form-action 'none'` and `frame-ancestors 'none'` to the Tauri CSP configuration, preventing clickjacking.
- [x] **E2E Credential Safety**: Confirmed that `CN_API_KEY` processing strictly validates its presence without echoing it to logs or subprocess artifacts in Webdriver testing.
- [x] **Dependency Check**: Verified workspaces for orphan dependencies and ran vulnerability assessments. All clear.
