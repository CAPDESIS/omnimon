OmniMon v6.4.1: Modo Pro IA, Layout Split y Hardening Final

OmniMon 6.4.1 agrega modo profesional en IA, botones Preguntar IA en dashboards, streaming real de tokens en backend, layout split, mejor i18n, rutas CLI mas seguras y una UX desktop mas limpia.

10 de marzo de 2026

Vision general del release

OmniMon v6.4.1 afina la experiencia del operador alrededor de IA, dashboards, consistencia visual y confiabilidad. Esta entrega introduce un flujo de IA más capaz, termina el streaming real de tokens en backend, mejora la ergonomía desktop con layout split y dividers funcionales, reemplaza affordances cargadas de emojis por iconos Lucide, amplía i18n y elimina más rutas de runtime riesgosas en CLI y automatización de releases.

Mejoras en el flujo de IA

  • Modo profesional en IA para usuarios avanzados que necesitan análisis más profundos
  • Botones Preguntar IA en dashboards para abrir análisis contextual directo desde vistas del sistema
  • Streaming real de tokens en backend para mostrar salida incremental en lugar de esperar una sola respuesta final
  • Coverage y fixes a flaky tests para dar más estabilidad al flujo de IA bajo ejecuciones repetidas

Pulido desktop y layout

  • Modo split layout para un flujo side-by-side más profesional en pantallas densas
  • Divider redimensionable ahora sí activo y funcional
  • Migración a iconos Lucide en lugar de affordances basadas en emojis
  • Fixes de transparencias para mejorar legibilidad en paneles antes lavados o confusos

i18n y consistencia

  • 60+ strings migradas a i18n en componentes de red y alertas
  • Superficies de red y alertas más consistentes entre inglés y español
  • Exports y mocks corregidos en processIcons y tests de app para reducir drift visual entre entornos

Hardening y seguridad interna

  • CLI más segura en runtime al eliminar los últimos expect() peligrosos
  • Generación de checksums mejorada en SHA256SUMS.txt durante release
  • Refresh de dependencias con quinn-proto actualizado para cubrir un CVE documentado
  • Más limpieza de unwrap/expect para reducir caminos propensos a panic

Tests y cobertura

  • Tests desktop ampliados para automations y plugins
  • Meta de coverage al 85% con fixes a flaky tests para una validación más estable en CI
  • Landing y superficie pública actualizadas junto con el pass de tests para mantener docs y producto sincronizados
