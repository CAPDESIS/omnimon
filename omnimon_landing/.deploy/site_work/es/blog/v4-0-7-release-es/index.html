OmniMon v4.0.7 - Documentacion, Compliance y Alineacion de Versiones

Refresca la documentacion, captura el estado de compliance y auditorias, y alinea las versiones visibles en desktop, CLI, TUI y metadata cloud.

5 de marzo de 2026

Vision general del release

OmniMon v4.0.7 se centra en hacer el producto mas confiable y mas claro de operar. Esta entrega refresca la documentacion publica, captura la postura de compliance y alinea las versiones visibles para que app, CLI, TUI e integraciones cloud cuenten la misma historia.

Documentacion

  • README principal actualizado para reflejar la superficie publica de OmniMon y su instalacion
  • Nuevos docs para auditoria, referencia de comandos, tracking de CVEs y compliance NIST
  • docs/CLI_MANUAL.md expandido con cobertura completa del CLI y ejemplos practicos

Compliance y auditoria

  • Resultados de cargo audit y guia de remediacion documentados
  • Controles seleccionados de NIST SP 800-53 mapeados contra salvaguardas implementadas
  • Gaps de coverage marcados para priorizar siguientes pasos

Alineacion de versiones

  • Footer desktop, metadata de Tauri About, banner CLI, titulo TUI y user agent cloud alineados a una misma version
  • Reduce confusion en soporte, capturas y verificacion de releases
