OmniMon v4.3.0: UI Responsiva, Paridad Safari y Chat OpenRouter

Una versión pulida con UI completamente responsiva, paridad de Safari para seguimiento de pestañas e integración OpenRouter para chat con IA.

14 de diciembre de 2025

Novedades en v4.3.0

OmniMon v4.3.0 se enfoca en pulido, paridad de plataformas y expansión de proveedores de IA.

Aspectos Destacados

  • UI Completamente Responsiva - Cada vista se adapta a cualquier tamaño de pantalla. Tablas de procesos, paneles de red y dashboards de seguridad funcionan en pantallas pequeñas sin scroll horizontal.
  • Seguimiento de Pestañas Safari - La integración Chrome DevTools Protocol ahora cubre Safari junto con Chrome, Brave, Edge y Arc. Paridad completa en todos los navegadores principales.
  • Integración Chat OpenRouter - Además de Ollama para IA local, ahora puedes conectar a OpenRouter para acceder a GPT-4, Claude y otros modelos cloud directamente desde OmniMon.
  • Accesibilidad Mejorada - Etiquetas ARIA, navegación por teclado y gestión de foco en todos los elementos interactivos.
  • Endurecimiento de Event Listeners - Ciclo de vida de event listeners optimizado para prevenir fugas de memoria en sesiones prolongadas.

Detalles Técnicos

La UI responsiva aprovecha los runes de Svelte 5 para breakpoints de layout reactivos sin overhead de CSS media queries. La integración Safari requirió manejo personalizado de WebSocket para el DevTools Protocol debido a la implementación no estándar de Apple.

Instalación

macOS:

brew tap chochy2001/omnimon
brew install --cask omnimon

Linux:

curl -fsSL https://get.omnimon.com.mx | bash

Windows: Descarga el instalador .msi desde la página de releases.
