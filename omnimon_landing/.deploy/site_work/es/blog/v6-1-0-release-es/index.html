OmniMon v6.1.0 - Seguridad Endurecida, Streaming IA y Alertas Agrupadas

OmniMon 6.1.0 se enfoca en distribucion verificable, manejo mas seguro de claves, mejor analisis contextual y menos ruido operativo entre desktop, CLI y flujos con IA.

9 de marzo de 2026

Vision general del release

OmniMon v6.1.0 es una version centrada en confiabilidad y seguridad, pero tambien en que el producto sea mas util en el trabajo diario. Esta entrega endurece la integridad del release, elimina fallbacks de credenciales en texto plano, agrega streaming de tokens en IA y reduce el ruido de alertas con agrupacion y debounce.

Seguridad endurecida

  • Llave real Ed25519 para el auto-updater en lugar del placeholder anterior
  • Solo keyring nativo: las API keys dejan de caer a almacenamiento en texto plano
  • Protecciones del ciclo de vida de claves: zeroize, HKDF-SHA256 y omnimon config rotate-key
  • Firma de releases con Ed25519 y checksums SHA-256 para verificar binarios
  • Defensa contra prompt injection ampliada a 25 patrones entre frontend y backend
  • CI endurecido con GitHub Actions pinneadas y auditorias cargo audit + bun audit

Correcciones operativas

  • MITRE actualizado: la tecnica obsoleta T1043 se corrige a T1071
  • Contexto CPU arreglado para que los reportes IA distingan entre total y per-core
  • Markdown corregido en alertas y chat IA
  • Mejoras en AIChat: auto-scroll y mejor respeto del idioma
  • Alertas de salud con debounce tras tres lecturas consecutivas
  • Alertas agrupadas por proceso para evitar duplicados apilados

Nuevas capacidades

  • Procesos agrupados por nombre como Chrome ×15 con detalle expandible
  • Iconos nativos de aplicaciones en la tabla de procesos
  • Dashboards clickeables con consultas IA contextuales
  • Streaming de tokens y 7 presets para analisis rapido
  • 5 herramientas de tool calling: detalles de proceso, detalles de red, security scan, explicacion de proceso y resumen del sistema
  • TTL configurable de cache IA entre 0 y 60 minutos
  • Sistema de temas: Dark, Light y Cyberpunk
  • Mas paridad CLI para network y rules

Rendimiento y calidad

  • Polling migrado a eventos push de Tauri para refresco mas ligero
  • ~500 clones de String por tick eliminados en un watcher hot path
  • App.svelte descompuesto de 1757 lineas en modulos mas enfocados
  • 857 tests entre Rust y frontend con gates de coverage mas fuertes

brew tap chochy2001/omnimon && brew install --cask omnimon

# Linux
