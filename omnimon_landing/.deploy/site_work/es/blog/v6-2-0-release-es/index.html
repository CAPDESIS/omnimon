OmniMon v6.2.0: Analisis Avanzado de Red, Alertas y Acciones IA

OmniMon 6.2.0 expande el producto hacia visibilidad completa de red con dashboards en vivo, alertas configurables, captura cross-platform y acciones de IA contextual en desktop y CLI.

9 de marzo de 2026

Vision general del release

OmniMon v6.2.0 convierte el trafico de red en un flujo de trabajo de primera clase. Esta entrega agrega captura de conexiones activas en macOS, Linux y Windows, publica un dashboard completo de red en la app desktop, introduce alertas configurables y amplía la capa de IA con analisis de trafico y acciones guiadas por contexto.

Analisis avanzado de red

  • Captura cross-platform de conexiones activas usando lsof en macOS, /proc/net en Linux y tablas TCP/UDP nativas en Windows con fallbacks seguros
  • Modelo NetworkConnection con protocolo, estado, throughput, hostname y contexto GeoIP
  • Historial NetworkSnapshot con buffer circular de 60 snapshots, equivalente a unos 5 minutos de trafico
  • Reverse DNS asíncrono con cache, TTL y limites de concurrencia
  • Filtros ricos por protocolo, puerto, proceso, PID, host, throughput, localhost y estado established
  • Integracion con watcher mediante captura cada 6 segundos y eventos push network-update

Alertas de red

  • Reglas configurables para picos de bandwidth, conexiones externas, puertos sospechosos, spikes por proceso, exceso de conexiones y destinos sospechosos
  • Debounce y cooldown para evitar disparos por una sola muestra ruidosa
  • Reglas de fabrica para alto bandwidth, puertos sospechosos, spikes x5 y mas de 200 conexiones simultaneas
  • Configuracion persistente con toggles, modal de creacion y preferencias guardadas
  • Notificaciones integradas con acciones directas para investigar o preguntarle a la IA

Dashboard desktop

  • NetworkDashboard.svelte con metricas en tiempo real, conexiones activas y sparklines
  • ConnectionsTable.svelte con ordenamiento y filtros por protocolo, proceso, dominio y trafico minimo
  • ProcessNetworkView.svelte para agrupar conexiones por proceso y distribucion de bandwidth
  • NetworkMap.svelte refactorizado como grafo SVG interactivo con trafico animado y pulsos en nodos activos
  • ConnectionDetail.svelte con IP, hostname, pais, throughput y accesos rapidos a IA

Flujos de IA para red

  • Nuevos presets para analizar trafico y detectar anomalias
  • Contexto de red inyectado en prompts para que el chat razone sobre conexiones y puertos abiertos
  • Accion contextual “¿Que es esto?” desde el detalle de cada conexion
  • Tool calling close_connection con confirmacion en frontend
  • Traducciones EN/ES para herramientas y workflows de red

CLI y hardening cross-platform

  • Nueva superficie CLI: omnimon network --connections, --filter, --alerts, --top y --watch
  • Hardening en Windows con APIs TCP/UDP nativas y fallback a netstat
  • Correcciones en Linux para resolucion inode→PID, IPv6 y fallback a ss
  • Hardening en macOS con deteccion automatica de lsof y timeouts mas estrictos

Calidad y documentacion

  • 941 tests entre Rust y frontend
  • Mas tests de parsing para lsof, /proc/net, netstat y ss
  • Cobertura frontend para dashboard de red, tabla, alertas, vista por proceso y store
  • Nueva documentacion en docs/NETWORK_ANALYSIS.md y referencias de comandos actualizadas

Instalar

# macOS
brew tap chochy2001/omnimon && brew install --cask omnimon

# Linux
curl -fsSL https://get.omnimon.com.mx | bash

# Windows
winget install chochy2001.omnimon
