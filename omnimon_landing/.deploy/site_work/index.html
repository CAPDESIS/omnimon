Release 6.5.0

Lo mas importante que cambia en esta version

Esta landing ya no arrastra contenido viejo: refleja el release actual, explica el estado real del producto y enlaza acciones verificables.

Kill dialog inteligente

Al terminar navegadores, el dialogo muestra las pestanas abiertas que se cerraran. Nuevo boton "Preguntar a la IA" para analizar si es seguro terminar un proceso.

Graficas dinamicas corregidas

Sparklines y modales de graficas ahora renderizan de forma confiable con escalado dinamico Y, reintentos automaticos y sincronizacion incremental de datos.

Sistema de temas unificado

Se elimino el sistema de temas duplicado que causaba conflictos. Un solo motor de temas (dark, light, cyberpunk) con auto-deteccion de preferencia del sistema.

Detalles de proceso mejorados

El modal de detalles ahora muestra pestanas del navegador en modo basico, no solo en modo Pro. Layout full-width responsive para todos los paneles.

Desktop nativo

UI en Tauri + Svelte 5 con telemetria en tiempo real, paneles de seguridad y temas integrados.

CLI y TUI

Mismas capacidades clave desde terminal para servidores, automatizacion y diagnosticos rapidos.

Seguridad operativa

Auditoria local, reglas, telemetria de red y controles para reducir errores y detectar anomalias antes.

FAQ

Preguntas frecuentes

Que incluye la version 6.5.0?

Incluye kill dialog inteligente con pestanas del navegador y boton de IA, graficas dinamicas corregidas, sistema de temas unificado sin conflictos, y detalles de proceso mejorados con tabs visibles en modo basico.

En que plataformas funciona OmniMon?

OmniMon esta pensado para macOS, Windows y Linux, con app de escritorio, CLI y TUI compartiendo la misma base de capacidades.

La IA es obligatoria?

No. Puedes usar OmniMon como monitor y panel de seguridad sin IA, o activar proveedores locales y cloud cuando necesites analisis asistido.

Como verifico una descarga?

Descarga el artefacto desde GitHub Releases y compara su hash con `SHA256SUMS.txt`. Si necesitas mas garantia, valida tambien la firma del release.
